# Market Basket Analysis using Apriori Algorithm

## Description

This project performs Market Basket Analysis on the Groceries dataset using the Apriori algorithm to identify frequently purchased products and generate association rules.

## Experiments

- **Data Preprocessing:** Loads and cleans the Groceries dataset.
- **Transaction Formation:** Groups products into customer shopping baskets.
- **Apriori Algorithm:** Generates frequent itemsets.
- **Association Rule Mining:** Extracts rules using support, confidence and lift.
- **Rule Analysis:** Identifies positive associations between products.

## Technologies Used

- Python
- Pandas
- Mlxtend
- Jupyter Notebook

## Dataset

[Groceries Dataset – Kaggle](https://www.kaggle.com/datasets/heeraldedhia/groceries-dataset)

## How to Run

1. Install the required libraries using `pip install pandas mlxtend`.
2. Download the Groceries dataset from Kaggle.
3. Place the CSV file in the notebook folder.
4. Open the notebook in Jupyter Notebook.
5. Run each cell in order.

## Objective

To understand and implement Market Basket Analysis using the Apriori algorithm and discover relationships between frequently purchased products.
